# Voxa для ПК

Лаунчер Minecraft: Java Edition для Windows от VegasDev, в том же дизайне «Витрины», что и Voxa на Android.

Сейчас умеет:
- создавать сборки Vanilla и Fabric на любой релизной версии;
- сам скачивать нужную Java (Adoptium) под версию игры;
- запускать игру, у каждой сборки своя папка с модами и мирами;
- входить через аккаунт Microsoft (Настройки → «Войти через Microsoft»): игра идёт под твоим профилем, пускает на сервера с проверкой лицензии, виден скин аккаунта. Без входа — офлайн-ник, как раньше.

Как устроен вход: окно со страницей Microsoft (пароль Voxa не видит) → Xbox Live → токен Minecraft, код в `lib/msauth.js`. Токены лежат в `%APPDATA%\Voxa\account.bin`, зашифрованные средствами Windows, перед запуском вход сам обновляется. «Выйти» стирает их.

Скачать: раздел Releases, тег `test`.

Разработка: `npm install`, `npm start`. Проверка: `npm test`. Сборка .exe: `npm run dist`.
