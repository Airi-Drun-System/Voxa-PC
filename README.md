# Voxa для ПК

Лаунчер Minecraft: Java Edition для Windows от VegasDev, в том же дизайне «Витрины», что и Voxa на Android.

Сейчас умеет:
- создавать сборки Vanilla и Fabric на любой релизной версии;
- сам скачивать нужную Java (Adoptium) под версию игры;
- запускать игру, у каждой сборки своя папка с модами и мирами.

Скачать: раздел Releases, тег `test`.

Разработка: `npm install`, `npm start`. Проверка: `npm test`. Сборка .exe: `npm run dist`.
