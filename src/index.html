    Отдельный режим
    
Horizon

    
Minecraft Java 26.3, заново написанный на Rust. Мир грузится в разы быстрее и ест меньше памяти. Работает через свой лаунчер, Voxa его ставит и запускает.

    
Проверяю…

    

      
      
      
      
    

  

  
    
    
  • Неофициальный проект энтузиастов, не от Mojang. Voxa скачивает его только с GitHub автора и сверяет контрольную сумму.
    • 
    
  • Нужна своя копия Minecraft Java Edition: при первом запуске Horizon готовит игру из версии 26.3. Если её нет, он предложит скачать.
    • 
    
  • Моды Fabric и шейдеры тут не работают. У Horizon свои моды, они ставятся внутри его лаунчера.
    • 
    
  • Вход Microsoft пока не поддерживается: одиночная игра, LAN и сервера без проверки аккаунта.
    • 
    
  • Нужна видеокарта с Vulkan, любая современная подойдёт.
    •
